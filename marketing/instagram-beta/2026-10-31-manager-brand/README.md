# After · 개인 소개 매니저 브랜드 시안

2026-10-31 승인 방향: **단정하지만 위트 있게 — 친근한 소개 매니저**.
2026-11-01 사용자가 **A · 이어주는 after**를 확정했다. 앱·아이콘 원본은 `brand/after-logo.json`, 재생성은 `node scripts/generate-brand-assets.mjs`를 따른다. B/C는 이전 탐색안을 보관한다. SNS 게시나 계정 사진 변경은 별도 요청 시 진행한다.

## 구성

- `preview.html`: 로고 세 방향 비교, 선택한 로고에 맞춘 게시물, 캡션 복사·다운로드.
- `logos/`: A 전용 레터링(ft 연결), B 두 쉼표, C 기울인 서명과 쉼표. 컬러·단색·반전 워드마크/심벌과 앱 아이콘 SVG 총 21종. 폰트 설치 없이 선명한 경로 기반 벡터.
- `exports/{a,b,c}/`: 각 방향별 피드 6개(1080×1350), 스토리 2개(1080×1920), 프로필 아이콘 1개(1024×1024).
- `captions.txt`, `campaign.mjs`: 게시물별 캡션과 게시 조건.
- `review/`: 모바일·데스크톱 검토 화면과 자동 검사 결과.

## 메시지와 사실

한 번에 한 사람, 공개 프로필을 바탕으로 한 소개, 서로 확인하는 약속을 강조한다.
회사 이메일 필수·동일 직장 지역 제한·성사 보장·인원 수·가짜 후기·임의 베타 마감일은 쓰지 않는다.
직장인을 중심으로 모집하되 프리랜서·자영업자를 배제하지 않는다.

프로필 코칭(02)과 매니저 해설(04)은 해당 운영 플래그가 꺼져 있으므로 **기능 공개 후 게시하는 초안**이다.
그 외 게시물도 로고와 문구를 최종 검토한 뒤 게시한다. 이 작업은 SNS 게시·광고 집행을 포함하지 않는다.
매니저·프로필·약속의 대화와 데이터는 가상 예시이고 각 이미지 안에 표시했다.

## 자산 출처

- `assets/first-coffee.jpg`: 기존 앱 `public/brand/after-first-conversation.jpg` 그대로 복사. 기존 AI 연출 이미지이며 실제 회원이나 제휴 장소가 아니다.
- 매니저 캐릭터: `src/assets/concierge/{female,male}.webp` 그대로 사용. 승인된 캐릭터를 다시 그리거나 단순화하지 않았다. 생성 원문은 해당 폴더의 `.prompt.txt`에 있다.
- B/C 레터링: 저장소 Wanted Sans Variable에서 SVG 경로 추출. Copyright 2024 Wanted Lab, SIL Open Font License 1.1. A 레터링과 세 기하 심벌은 이 시안을 위해 직접 작성했다. 상표 등록·유사성 법적 검토 완료를 의미하지 않는다.
- 새 유료 이미지·영상 생성 또는 LLM API 호출 없음. 텍스트와 벡터·사진 배치는 HTML/CSS로 제작했다.

## 재생성

1. 임시 Python 환경에 `fonttools brotli`를 설치하고 `create-logos.py` 실행.
2. 저장소의 Playwright를 이용해 `node marketing/instagram-beta/2026-10-31-manager-brand/render.mjs` 실행.
3. 같은 명령에 `--serve`를 붙이면 127.0.0.1:5237에서 시안 페이지를 연다. 이 캠페인과 공개 폰트 경로만 제공하며 `.env` 등은 제공하지 않는다.

확정된 A 로고를 DESIGN.md, 앱 Logo.tsx, 파비콘, 스토어 아이콘에 함께 적용한다. 게시물 02/04의 운영 기능 공개 조건은 그대로 유지한다.

## 검증

피드 18개·스토리 6개·프로필 아이콘 3개와 SVG 21개를 내보냈다. 1440px/390px에서 이미지·폰트 로딩, 가로 넘침, 콘텐츠 영역, 로고 선택 연동, 서버 파일 접근 범위 및 잘못된 로고 URL 입력을 확인했다. 독립 검토의 수정 항목 3개는 모두 해결됐고, 최종 판정 범위는 “시안 검토용 배포”다. 자세한 근거는 `review/checks.json`과 `review/verdict.md`에 있다.
