# Wanted Sans Variable

Source: https://github.com/wanteddev/wanted-sans/tree/main/packages/wanted-sans

Retrieved 2026-10-24 from the official repository. `WantedSansVariable.css` and its 92 Unicode-range WOFF2 subsets are self-hosted; the CSS font URLs were changed to local relative paths. Glyph data is unmodified. Only the subsets needed by visible text are requested. `font-display: swap` preserves readable fallback text while loading.
