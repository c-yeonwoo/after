# 확정 로고 적용 검증 — 2026-11-01

사용자가 승인한 A안 “이어주는 after”, revision `after-ft-1` 적용 범위의 검증이다.

- SVG 경로와 viewBox: 승인 시안과 canonical JSON·앱·생성 SVG 동일.
- 웹: Chromium/WebKit, 390px 밝은/어두운 테마에서 랜딩·로그인·가입·기존 로컬 합성 계정 홈 헤더, 1440px 데스크톱 랜딩 확인. 실제 홈 네비게이션이 나타나고 로그인 폼이 제거된 상태에서 캡처했다.
- 로고 비율·테마의 currentColor 상속·가로 넘침·파비콘 revision URL과 HTTP 응답 확인.
- 아이콘: iOS 1024² 불투명 RGB 정사각형, Apple Touch 180², 웹 512², OG1200×630, 스플래시2732². iOS PNG와 앱스토어 원본 동일.
- 타입·린트·도구/대비/AI/인증/일정 회귀·빌드: `npm run check` 통과. 코드·자산·문서 독립 검토 후 홈 캡처 1건 재촬영 근거 확인, 최종 ship 판정.

시각 검사에서 모델 함수 요청은 차단했다. 실제 발송·결제·회원 변경은 하지 않았다. 홈 검증은 공통 헤더 범위이며 소개/결제 라이프사이클 전체 재검증을 뜻하지 않는다. 네이티브 실기기·스토어 업로드·SNS 게시도 이 검증 범위에 포함하지 않는다. 기존 테스트 계정의 프로필·약속을 초기화하지 않았다.

`checks.json`에 세부 검증값이 있으며 `comparison.png`는 기존·확정·다크모드의 로그인 상단 비교다. `webkit-home-dark.png`는 실제 홈 헤더 재촬영 근거다. CI·운영 배포 결과는 해당 PR의 Release gate를 따른다.
