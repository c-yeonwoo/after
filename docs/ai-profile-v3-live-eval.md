# 인터뷰형 소개장 v3 운영 모델 검증

2026-10-17. 운영 `compose-profile-v3`에 합성 인터뷰만 전송했다. 실제 회원의 이름·사진·연락처·원문은 평가에 사용하지 않았다. 이 문서는 실사용자 평가가 아닌 개발자 표본 점검이다.

## 장애와 수정

| 관찰 | 확인된 원인 | 조치 |
| --- | --- | --- |
| 분석/생성 모두 실패 | Anthropic `401 authentication_error`; 등록된 secret의 존재만으로 유효성을 보장할 수 없었다 | 운영 API 키 교체 후 실제 분석 성공 확인 |
| 생성 문장은 왔으나 `invalid_output` | 모델이 대화 소재 3개를 반환; 공개 계약은 최대 2개 | 최대 2개로 정규화하고 제목·요약·소재까지 근거 검토에 포함 |
| 이해 요약에 “건강한 생활 리듬” 등장 | 원문에는 운동의 이유나 건강 목표가 없었다 | 사용자가 확인하는 요약을 직접 진술 사실에서만 구성 |
| 단답 소개장의 제목이 “~하는 사람” | 제3자 시점 프롬프트와 반복 표현 | 1인칭 해요체 제목, 반복 제거를 편집 지침에 명시 |
| 퇴근 후 선택을 “쉬는 날”로 확대 | 선택지만 모델에 전달되어 질문의 시간 범위가 빠졌다 | 모든 자료에 원래 질문을 붙이고 검토기에서 시간·상황 범위 확인 |

## 실제 생성 표본

아래 결과는 위 조치를 진행하면서 나온 모델 응답을 사람이 원자료와 비교한 것이다. 총 7개의 합성 소개장 생성이 성공했다. 최종 프롬프트 `profile-story-v3-4`의 성공 표본은 그중 1개다. 일부 초기 표본의 문체 문제는 위 조치의 계기가 되었으므로 최종 품질 실적으로 세지 않는다.

| 재료 | 확인한 내용 |
| --- | --- |
| 운동·첫 커피·영화/식당 | 세 질문의 답이 분리되고 주 3회, 두 번째 만남, 최근 본 영화가 보존됨 |
| 짧은 구어체 `음..`·걷기·독립영화 희망 | 감탄사를 제목으로 쓰지 않고 완성 문장으로 정리함. 초기 제목의 제3자 시점은 수정 후 재시험에서 사라짐 |
| 운동하지 않음·등산 희망·해외여행 경험 없음 | 부정, 희망, 미경험을 현재의 취미/경험으로 바꾸지 않음 |
| 선택형 답변만 제공 | 피아노·함께 걷기·음악을 질문별로 표현하고 근거 없는 직업/성격은 추가하지 않음 |

최종 `v3-4`의 부정·희망 사례에서 실제로 받은 공개 답변은 다음과 같다.

> **퇴근 후에는 어떻게 보내세요?** 퇴근 후 시간이 생기면 주로 혼자 푹 쉬어요. 요즘은 운동을 안 하는데, 언젠가 등산을 시작해보고 싶어요.
>
> **어떤 만남에서 편해지나요?** 술자리는 불편해서 첫 만남엔 짧게 커피만 마시는 자리가 편해요.
>
> **만나면 어떤 이야기를 나누고 싶나요?** 여행 이야기를 좋아해서 만나면 자연스럽게 꺼내고 싶어요. 다만 해외여행은 아직 가본 적이 없어요.

원문에 없는 운동 습관, 등산 경험, 해외여행 경험을 추가하지 않았다. 질문 맥락인 **퇴근 후**도 유지했다. 제목은 “첫 만남은 짧게 커피 한잔이 좋아요”였다. 글은 이전의 원문 연결본보다 읽기 쉬워졌지만, 모든 사람이 “나다운 소개장”이라고 느낄지는 이 표본으로 증명할 수 없다.

## 아직 남은 출시 검증

- 설계에서 정한 **최종 버전의 명확한 합성 입력 10회 연속 성공**은 아직 미달이다. 운영 계정별 일일 생성 한도를 우회하거나 운영 데이터의 카운터를 지우지 않았다.
- 실제 작성자 5–8명과 독자 관찰, 나다움·구체성의 사람 평가 4/5 목표는 아직 수행하지 않았다.
- 품질 판단은 소수의 합성 입력에 대한 사람이 읽은 점검이며, 허구가 절대 없다는 보증이 아니다. 공개 전에는 회원의 최종 승인을 계속 요구한다.
