# 애프터 카카오 알림톡 도입 체크리스트

상태: **대표가 After 채널 생성 완료를 알려줌 / 비즈니스·템플릿 승인 및 실제 발송 연동 미확인**. 검색용 ID: **애프터선셋**. 채널 URL·공급자 채널 ID는 검색용 ID와 다르므로 추정해서 설정하지 않는다. 현재 앱의 인앱 알림·iOS 푸시와 카카오 발송을 혼동하지 않는다. 갱신 2026-10-17.

## 대표가 먼저 할 일

1. 생성한 `After` 채널(검색용 ID `애프터선셋`)을 재사용한다. 중복 생성하지 않는다. [채널 관리자센터](https://center-pf.kakao.com/)에서 실제 URL·승인 상태를 확인한다.
2. 홈페이지는 `https://aftersunset.kr`, 소개는 `직장인을 위한 소개와 약속 조율 서비스`로 설정한다. 대표·사업자 정보는 실제 증빙과 일치시킨다.
3. 비즈니스 채널 전환을 신청하고, 홈 공개와 고객센터 연락처를 설정한다. 실제 운영 가능한 연락처만 등록한다.
4. 기존 SOLAPI 계정의 카카오 채널 메뉴에서 연결한다. 관리자 본인 휴대전화 인증은 대표가 직접 진행한다.
5. 아래 템플릿을 등록하고 심사받는다. **소개팅 업종의 채널·메시지 이용 가능 여부와 후기 요청의 정보성 인정 여부를 SOLAPI/카카오에 확인한다. 승인 전 가능하다고 단정하지 않는다.**
6. 채널 URL과 승인 상태를 알려준다. 이후 연동에 필요한 채널 ID·템플릿 ID를 확인한다. API 비밀키는 채팅에 보내지 않고 Supabase Secrets에 저장한다.

카카오는 비즈니스 전환·홈 공개·고객센터 정보를 선행 조건으로 안내하며, 승인된 정보성 템플릿만 알림톡 발송에 사용할 수 있다. 채널 친구 추가는 알림톡 수신의 필수 조건이 아니다. [카카오 공식 안내](https://kakaobusiness.gitbook.io/main/ad/infotalk)

## 심사용 템플릿 초안

모두 정보 안내에만 사용한다. 혜택·구매 유도·새 상대 추천 같은 홍보 문구를 섞지 않는다. 상대 이름·회사·사진·대화·정확한 만남 장소는 잠금화면에 노출하지 않고 로그인한 앱 안에서 보여준다. `#{약속일시}`는 한국 시간으로 표시한다. 등록 버튼은 `내용확인`으로 고정하고 모바일/PC 링크 모두 `https://aftersunset.kr/notifications`를 사용한다. URL에 개인정보·인증 토큰을 넣지 않는다.

후기 템플릿은 심사 결과에 따라 알림톡이 아닌 인앱만 유지할 수 있다. 템플릿의 승인은 보장하지 않는다. SOLAPI는 비즈니스 채널 연결 후 템플릿 등록을 안내하고 있으며, 실패 시 SMS 대체 발송이 기본일 수 있어 명시적 비활성화가 필요하다. [SOLAPI 안내](https://solapi.com/guides/kakao-faq)

## 개발 작업: 채널 승인 뒤 별도 구현

- 기존 Supabase 알림 원장을 기준으로 SOLAPI 발송 작업자를 추가한다. Make에 회원/전화번호/상대 정보를 복제하지 않는다. 로그인용 카카오 OAuth 메시지 권한으로 대체하지 않는다.
- `알림 ID + 채널` 기준 멱등성, 임대·재시도·최대 횟수·실패 격리. 공급자 응답이 모호하면 즉시 재발송하지 않고 메시지 ID로 조회한다.
- 템플릿 allowlist만 사용. 외부 웹훅 인증·재전송 방지·순서 역전 처리. 발송 직전 탈퇴·취소·참석 완료·후기 완료·수신 설정·기한을 재검사한다.
- `미연결 / 접수 / 전달 확인 / 실패 / 결과 불명 / 앱 열람`을 분리한다. API 접수 성공은 읽음도 실제 기기 수신도 아니다. 공급자가 읽음 상태를 제공한다고 가정하지 않는다.
- **현재 안전 기준은 인앱 안내의 읽음 표시가 있는 양측만 참석 미응답 자동취소·경고 대상이다.** 카카오 전달 확인만으로 경고 대상을 늘리는 정책은 별도 결정·안내·검증 전까지 적용하지 않는다. 안내 확인이 없거나 한 명만 참석을 확인한 약속은 운영자가 연락한다.
- 취소·티켓 복구는 DB 원자 처리 이후 알린다. 현금 환불이라고 표현하지 않는다.
- SMS fallback은 기본 OFF. 사용자 요청 없이 잔액 충전·자동충전·유료 발송을 켜지 않는다. 알림 비용/실패율·재시도·미확인 약속을 운영 콘솔에 노출한다.
- 발송 위탁·전화번호 이용 목적·보유/삭제·수신 안내와 선택 설정을 점검한다. 마케팅 동의와 서비스 안내를 혼용하지 않는다. 필수 안내 범위와 법적 문구는 출시 전 별도 확인한다.
- 후기 넛지는 야간 방해를 피하도록 **외부 발송은 익일 오전 10시 권고**. 인앱 자정 생성과 외부 발송 시간을 분리한다. 이 시간 제어는 아직 구현되지 않았다.

## 실제 발송 전 통과 조건

1. 사업자·채널·템플릿 승인 및 업종 이용 가능 확인.
2. 개인정보 처리·발송 안내·수신 설정 점검.
3. 대표가 소유한 수신 번호로 승인받아 최소 테스트 발송. 실제 요금 확인.
4. 정상 수신·차단/실패·결과 불명·재시도·중복·로그아웃 링크·모바일/PC 테스트.
5. 참석 확인/취소/탈퇴와 경합해 늦게 나가는 메시지 차단.
6. 운영 콘솔에서 실패와 연락 필요 대상이 누락되지 않는지 확인.

그전에는 `카카오 알림 발송 완료`로 표시하지 않으며, 운영자의 직접 연락을 베타 대체 절차로 둔다.
