## PR 순서

### A1 — 서버 기반 정리
- 정지·쉬는 여성의 카드는 열리지 않는다: `open_intro` 가 `eligible_profiles` 에 있는 여성의 카드만 고른다. 계정 정지·노쇼 제명 시 미열람 큐 카드 삭제.
- 쉬는 남성에게는 전송하지 않는다: `promote_intro_queue` 가 `paused_at is null` 일 때만 전송.
- 사진 필수(D5): `eligible_profiles`·`is_eligible_candidate` 가 `photo_url is not null and photo_state = 'approved'`.
- 9문항 제거(D6): `preference_agreement`·`admin_preference_compare` 와 `preference_answers` 쓰기 RPC 삭제(테이블은 보존).
- 남성 반환 알림: 거절·24시간 무응답으로 만남이 취소되면 남성에게 `meeting_released` 메일. enum 추가는 별도 파일.

### A2 — 화면 기반 정리
- 홈: 상태 문장 1 · 카드 1 · 행동 1. 진행 막대 삭제, "예약 대행 아님" 고지는 /ticket 한 곳, 도착 상태에서 "준비되면 알려드릴게요" 제거, 여성 "살펴볼 소개".
- 가입: 권역이 하나뿐이면 2단계 생략(자동 배정), 사진 필수, 완료 후 `/home`, 7단계 뒤 알림 메일 인증 1화면(건너뛰기 가능).
- 처리방침: 공개된 내부 메모 삭제, 처리 위탁에 Anthropic(국외)·Cloudflare·Resend 명시, 사진 필수로 이동. 정책 버전 올림.
- 9문항 화면 코드 삭제.

### B1 — 소개장 디자인 + 랜딩
- 토큰 교체(라이트·다크), Noto Serif KR(display·이름·소개글), 타입 스케일(본문 16/1.6, 라벨 12/600/자간 0, 대문자 없음).
- 프로필 상세: 번호·영문 키커 삭제, 이름 세리프 28, 한 줄 소개 인용, 소개글 세리프 17/1.8, 사진은 첫 문단 뒤(매트), 관심사·주제는 문장형.
- 그라데이션 플레이스홀더 → 단색. "애프터 · 자동 안내" 라벨 삭제.
- 랜딩: D1 약속 + 진행 3단계 + 남녀 비용·반환 + "화면 예시" 소개장. 스크롤 허용, og:image.

### B2 — 열기 전 공개 (D2 ①)
- `intro_queue.reason`(쌍별, 남성에게 보이는 운영자 한 줄). 운영자 큐 화면에서 카드마다 입력.
- `intro_teaser()` RPC: 남성의 맨 앞 전송 카드에 대해 나이·직무·한 줄 소개·겹치는 주제·reason 만. 이름·사진·소개글은 열기 전엔 없다.
- 열람 게이트에 티저 표시 후 "소개 티켓 1장 쓰고 열기".

### B3 — 확정 약속 흐름 (D1 B)
- `meet_places`(권역별, 운영자 관리: 이름·역·종류·주소·지도 링크·활성).
- 남성 요청 시트: 앞으로 14일 평일 저녁 슬롯 중 최대 3개 + 장소 1곳(목록에서) → 만남 티켓 사용과 함께 `meetings.options` 저장.
- 여성: 3안 중 하나 탭 → 즉시 확정(`accept_meeting_option`). "다른 날 제안"은 기존 날짜 보내기 흐름으로, "정중히 거절"은 기존 그대로.
- 확정 카드에 장소 지도 링크.
