## 3. 연령 등급

Apple 이 2025년에 등급을 **4+ / 9+ / 13+ / 16+ / 18+** 로 바꿨고, 설문에
`인앱 컨트롤`·`기능`·`의료·웰니스`·`폭력적 주제`·`소셜 미디어 기능` 항목이 추가됐다.

**설정: 18+ (수동 상향)**

Apple 은 "앱 정책상 최소 연령이 Apple 이 부여한 등급보다 높으면 더 높은 등급을
직접 설정할 수 있다"고 명시한다. 이 앱은 **재직 중인 성인만** 받으므로(회사 이메일
검증 + 생년월일 수집) 설문 결과와 무관하게 18+ 로 올린다.

설문에서 **사실대로** 답해야 하는 것:
- **소셜 미디어 기능 있음** — 사용자 간 1:1 채팅이 있다(`messages` 테이블)
- **사용자 생성 콘텐츠 있음** — 프로필 소개글·사진·채팅
- **콘텐츠 신고·사용자 차단 수단 없음** ← 현재 사실이다. 노쇼 신고는 "약속에 안
  나왔다"를 다루는 것이고 Apple 이 묻는 콘텐츠 신고가 아니다. §7 참고.
- 도박·폭력·약물·의료 항목: 전부 없음

세 번째 항목을 **있다고 답하면 안 된다.** 설문 답변은 심사에서 실제 앱과 대조되고,
사실과 다르면 그 자체가 리젝 사유가 된다. 순서상 §7 의 신고·차단을 먼저 구현하고
그다음에 "있음"으로 답하는 것이 맞다.

없다.

### 수집하지 않는 것 (명시적으로)

- **결제 정보** — `ticket_orders` 는 `order_id`·`amount`·`state` 만 저장한다.
  카드번호·유효기간이 스키마에 없다. 결제 수단은 PG(Toss)가 다룬다.
- **정확한 위치** — 좌표를 받지 않는다. `hub_id` 는 사용자가 고르는 권역
  라벨(`gangnam` 등)이고 GPS 가 아니다.
- **진단·크래시 데이터** — 서드파티로 나가는 것이 없다. 오류 리포팅 코드 자체를
  제거했고(Lovable 의존성 정리), 프로덕션 번들에 외부 `<script src>` 0건·추적
  도메인 호출 0건을 확인했다. → **서드파티 수집 신고 대상 아님.**
- 연락처 목록, 건강·피트니스, 검색 기록, 기기 ID, 광고 데이터: 전부 없음.

### 계정 삭제 (Guideline 5.1.1(v) 필수)

앱 안에서 완결된다 — `나 → 환경설정 → 탈퇴하기`. 서버에서 `withdraw_account()` 가
미완료 만남을 취소하고 티켓을 환불한 뒤 신원 컬럼을 비운다. **웹으로 내보내지
않는다**(Apple 이 요구하는 조건).

## 6. 결제 — 여기가 가장 복잡하다

만남 티켓은 앱 안에서 소비되는 디지털 서비스라 **Guideline 3.1.1(IAP 의무)**
대상이다. 그대로면 Toss 결제는 리젝된다.

한국은 전기통신사업법 개정으로 예외가 있고, 쓰려면 조건이 붙는다:

1. **StoreKit External Purchase Entitlement (KR)** 을 Apple 에 신청해 승인받는다
2. Xcode 에서 entitlement 를 켠다
3. 지정된 **StoreKit External Purchase API** 를 사용한다 (Capacitor 웹뷰에서
   Toss 결제창만 띄우는 방식으로는 조건을 못 채운다 — 네이티브 코드가 필요하다)
4. **대한민국에만 배포하는 별도 바이너리**를 제출한다

4번 조건은 이 서비스가 원래 한국 단독 운영이라 오히려 잘 맞는다. 문제는 3번이다 —
**현재 앱에는 해당 네이티브 코드가 없다.**

### 선택지

| | 내용 | 대가 |
|---|---|---|
| **A. IAP 로 판다** | Apple 인앱결제 사용 | 수수료 15~30%. 3만원 티켓에서 4,500~9,000원 |
| **B. External Purchase (KR)** | Toss 유지 | Entitlement 신청 + StoreKit 네이티브 구현. Apple 에 별도 수수료 규정 있음 |
| **C. 결제를 웹으로** | 앱에서 티켓을 팔지 않고 웹에서만 | 3.1.1 회피. 단 앱에서 웹 결제로 **유도하면 안 된다**(리더 앱 아닌 경우 금지) — 전환율이 크게 깎인다 |

**결정이 필요한 항목이다.** 지금은 Toss 가맹점 키도 미발급이라 어느 쪽도 착수 전이다.

|---|---|
| 신고 수단 | ⚠️ **노쇼 신고만 있다**(`reportNoShow`). 부적절한 프로필·메시지를 신고할 길이 없다 |
| 사용자 차단 | ⛔ **없다.** `block` 계열 기능이 코드에 존재하지 않는다 |
| 콘텐츠 필터링 | ⛔ 없다 |
| 연락 창구 | ⛔ 문의 채널이 `LEGAL_TODO` 에 미확정으로 남아 있다 |

노쇼 신고는 "약속에 안 나왔다"를 다루는 것이고 Apple 이 말하는 콘텐츠 신고가 아니다.
**1:1 채팅이 열리는 앱이라 이건 심사에서 걸릴 가능성이 높다.** 최소한 신고·차단
두 가지는 제출 전에 넣는 편이 안전하다.
