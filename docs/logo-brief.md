# 애프터 로고 브리프

현재 워드마크와 심벌 사양은 [애프터 리브랜딩 설계안](after-rebrand-plan.md)의 “로고와 앱 아이콘” 절을 따른다. SVG 원본과 재생성 절차는 [브랜드 자산 가이드](brand-assets.md)에 정리했다.

이 문서는 과거 이클립스 로고 탐색 기록을 대체한다. 이전 초안의 Eclipse 워드마크·초승달·로즈 팔레트는 현재 브랜드에 적용하지 않는다.

## 2026-10-31 개인 소개 매니저 로고 시안

사용자가 확정한 검토 방향은 “단정하지만 위트 있게 — 친근한 소개 매니저”다.
새 워드마크·심벌 3방향과 각 로고를 적용한 SNS 피드 6종·스토리 2종은
[브랜드·캠페인 시안](../marketing/instagram-beta/2026-10-31-manager-brand/README.md)에 보관한다.
최종 선택 전에는 앱과 SNS 프로필의 현재 로고를 교체하지 않는다.
