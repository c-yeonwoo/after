# 애프터 로고 브리프

## 현재 승인안 — 2026-11-01 “이어주는 after”

사용자는 “단정하지만 위트 있게 — 친근한 소개 매니저” 방향의 첫 번째 시안을 최종 선택했다. 소문자 `after`를 직접 그린 모노라인 워드마크에서 `f`와 `t`의 가로획이 이어지며, 독립 심벌도 같은 `f/t` 연결을 사용한다. 연결 형태가 사람 사이를 이어주는 개인 소개 매니저의 역할을 표현한다.

로고는 글꼴 텍스트가 아닌 고정 SVG 경로다. `after`를 유사한 글꼴로 다시 입력하거나 코럴 점·기존 `a` 링을 더하지 않는다. 워드마크와 심벌의 비율, 둥근 획 끝, 연결부를 보존한다. 제품 UI의 Wanted Sans와 화이트·핑크·웜화이트 팔레트, 승인된 매니저 캐릭터는 유지한다.

단일 원본은 [after-logo.json](../brand/after-logo.json)이며, 앱·아이콘·SNS 내보내기가 같은 경로를 공유한다. 앱 워드마크는 `sm` 높이 `28px`, 기본 `md` 높이 `32px`, 독립 심벌은 기본 `24×24px`이다. 테마에서는 `currentColor`로 읽기 쉬운 잉크를 상속한다. SVG 목록, 고정색 내보내기와 재생성 명령은 [브랜드 자산 가이드](brand-assets.md), UI 규칙은 [DESIGN.md](../DESIGN.md)를 따른다.

## 2026-10-31 개인 소개 매니저 로고 탐색 (과거 기록)

당시 검토 방향은 “단정하지만 위트 있게 — 친근한 소개 매니저”였다. 워드마크·심벌 3방향과 각 로고를 적용한 SNS 피드 6종·스토리 2종은 [브랜드·캠페인 시안](../marketing/instagram-beta/2026-10-31-manager-brand/README.md)에 보관한다. 이 폴더는 탐색 기록이며, 모든 시안을 현재 승인 자산으로 취급하지 않는다. 당시의 “최종 선택 전 교체하지 않는다”는 대기는 2026-11-01 첫 번째 안 승인으로 종료됐다.

이전 [리브랜딩 설계안](after-rebrand-plan.md)의 코럴 점·`a` 심벌과 더 오래된 Eclipse 워드마크·초승달·로즈 팔레트는 현재 로고 제작 기준이 아니다.
