# 토스페이먼츠 입점·계약심사 회신 초안

> **상태: 아래 미확정 항목을 해결하기 전에는 그대로 회신하지 마세요.**
> 운영 사이트는 베타 무료 티켓 발급 모드입니다. 토스 결제창·승인·취소는
> 2026-10-10 로컬 테스트키로 카드 30,000원 승인과 전액 취소까지 검증했지만,
> 운영 사이트의 결제 플래그는 꺼져 있습니다. 유료 청약철회 문구는 코드에
> 반영했으나 운영 배포·법률 검토와 사업자 전화번호의 공개 페이지 표기가 남았습니다.
> 카드사 최종 심사용 회신으로는 아직 보내지 마세요.

## 1. 계약심사 필수질문 답변

### 1) 판매 상품/서비스 설명

① **결제 상품/서비스 확인 가능한 URL**  
https://aftersunset.kr/store?kind=meeting
로그인한 회원만 이용할 수 있습니다. 검토 계정은 `review-male@eclps.kr` (일반 회원 권한)입니다.
비밀번호는 저장소에 넣지 않았으며, 운영자 로컬의 무시 파일 `.app-review-accounts.json`에서
`male.password`를 확인해 이메일 회신에 별도로 기재합니다. 로그인과 소개 대기 상태를
2026-10-09 운영 Supabase에서 확인했습니다. 결제는 비활성 상태라 실제 구매는 할 수 없습니다.

② **환불 정책 확인 가능한 URL**  
https://aftersunset.kr/terms
현재 약관은 베타 무료 운영과 유료 전환 후의 환불 원칙을 구분해 적었습니다.
유료 주문 전체가 미사용이면 법정 청약철회 기간에 전액 취소할 수 있고,
묶음의 일부가 사용되었다면 아직 제공되지 않은 잔여분은 문의 메일로 접수합니다.
사용분은 단순 변심에 따른 현금 환불 대상이 아니지만, 법정 권리와 회사 귀책사유는
제한하지 않습니다. 만남 불발은 현금 환급과 별개로 원래 만료일의 티켓을 반환합니다.
법률 검토와 운영 사이트 배포 전에는 확정된 운영 환불 정책으로 회신하지 않습니다.

③ **결제 상품/서비스 상세 내용**  
회사 이메일을 인증한 직장인 회원에게 한 번에 한 명씩 소개하고 만남 약속 조율을 돕는
온라인 소개 서비스입니다. 실물 배송이나 정기 구독이 아닌 티켓형 디지털 서비스입니다.

- 소개 티켓: 소개 프로필 열람에 사용합니다. 1장 5,000원, 5장 22,000원.
- 만남 티켓: 상대와 만남을 진행하고 일정을 조율하는 데 사용합니다. 1장 30,000원,
  3장 85,000원.
- 현재 구현된 카탈로그 기준 최고 단건 결제 금액은 만남 티켓 3장 묶음 85,000원입니다.
- 현재 베타에서는 결제를 받지 않고 운영자가 티켓을 무료 지급합니다. 위 가격은 코드에
  정의된 유료 전환용 가격이며 현재 웹에서 실결제가 가능한 상태를 뜻하지 않습니다.

④ **단건 결제 기준 상품 금액 최고가**  
85,000원 (만남 티켓 3장 묶음, 현재 구현된 가격 기준)  
※ 실제 입점·판매 가격으로 확정한 값인지 대표자 확인 필요.

**비회원 구매가 불가한 경우 테스트 계정 ID/PW**  
비회원 구매 불가. 검토 계정은 `review-male@eclps.kr`이며 `member` 권한만 있습니다.
ID/PW를 메일로 전달할 때 비밀번호를 이 문서나 PR에 복사하지 말고 위 로컬 무시 파일에서
확인합니다. 해당 계정은 로그인할 수 있고, 소개 1건과 무료 소개·만남 티켓을 확인할 수
있습니다. 결제 스토어는 무료 베타 신청 화면으로 표시됩니다.

### 4) 결제경로 PPT

**로컬 샌드박스 실화면 증빙:**
`../deliverables/toss-payment-flow-sandbox-evidence-2026-10-10-v3.pptx`.
토스의 웹/다운로드 불필요 앱 가이드에 맞춰 사업자정보·환불규정·로그인·상품·구매·
카드 결제창을 로컬 화면으로 캡처했습니다. 결제 완료·취소 슬라이드는 별도 선행
샌드박스 거래의 실화면이며, 같은 주문으로 보이도록 하지 않았습니다.
공개 사이트는 결제가 꺼져 있어 카드사 최종 심사용 **운영 결제경로 증빙은 아닙니다**.
기존 `../deliverables/toss-payment-flow-preconsultation.pptx`는 과거 사전 문의 자료입니다.

1. 로그인 → 티켓 스토어 진입
2. 상품 종류와 수량 선택 → 가격 및 제공기간·환불 안내 확인
3. 결제수단 선택 및 결제창 진행
4. 결제 완료 → 주문 결과 확인 → 티켓 지급 확인

3–4단계는 로컬 테스트 환경에서 검증했습니다. 기존 PPT는 당시의 사전 문의용 자료이므로
현 상태를 나타내지 않습니다. 유료 약관과 운영 결제가 공개된 뒤 실제 운영 화면을 새로
캡처해 카드사 심사용 PPT로 교체해야 합니다.
