첨부할 결제경로 증빙으로는 아직 사용할 수 없습니다. 실제 구현 및 샌드박스 결제·취소 검증
후 아래 흐름을 운영 사이트에서 캡처해 정식 PPT로 교체해야 합니다.

1. 로그인 → 티켓 스토어 진입
2. 상품 종류와 수량 선택 → 가격 및 제공기간·환불 안내 확인
3. 결제수단 선택 및 결제창 진행
4. 결제 완료 → 주문 결과 확인 → 티켓 지급 확인

3–4단계는 로컬 테스트 환경에서 검증했습니다. 기존 PPT는 당시의 사전 문의용 자료이므로
현 상태를 나타내지 않습니다. 유료 약관과 운영 결제가 공개된 뒤 실제 운영 화면을 새로
캡처해 카드사 심사용 PPT로 교체해야 합니다.
