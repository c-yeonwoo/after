로컬에서 `npm run release:check`로 타입·린트·대비·AI 합성 50건·웹 빌드·DB 576건·약속/알림/AI의 실제 두 연결 경합을 확인했다. `npm run build:app:dev`도 통과했다. `npm audit --omit=dev`의 high/critical 취약점은 0건이며, CI는 향후 high 이상을 차단한다. 전체 개발 의존성에는 Capacitor CLI의 `uuid` 경로로 moderate 3건이 남아 있어 별도 추적한다.

`npm run test:browser-e2e`는 **로컬 Supabase에서만** 합성 계정을 만들고 정확히 그 계정·사진만 삭제한다. 360/390/768/1440px 가로 넘침, 핵심 화면 WCAG serious/critical 검사, 남성 소개 열람·만남 요청 → 여성 수락·문의 접수 → 운영자 문의 답변·운영 홈/수급/시스템 열람을 실제 Chromium으로 통과한다. 테스트는 운영 DB URL을 거부한다. SQL 테스트의 전역 카운트 1건은 합성 데이터가 있는 로컬 DB에서도 독립적으로 통과하도록 범위를 좁혔다.

위 결과는 **자동화한 경로의 증거**다. 전체 테스트 매트릭스나 사람 사용성 검증을 완료했다고 뜻하지 않는다. PR CI와 `main` 릴리스 게이트 결과, `https://aftersunset.kr` 배포 커밋은 병합 후 별도로 대조한다.

## 제한 베타 전 사람 확인

- [ ] 실제 iOS Safari·Android Chrome에서 가입, 키보드·안전 영역·뒤로가기·인증 복귀·200% 확대·다크 모드를 확인한다. 데스크톱 Chromium/에뮬레이션만으로 대체하지 않는다.
- [ ] 운영자가 SQL 없이 사진 검수, 공급 부족, 신고/취소, 문의 응답, 자동화 중단·수기 복구를 리허설한다. 합성 E2E는 정상 경로의 일부만 다룬다.
- [ ] 실제 회사 메일·중요 알림 수신과 관리자 강화 인증/복구 수단을 확인한다.
- [ ] 타깃 직장인 약 5명에게 가입부터 약속까지 과업을 관찰하고, 불분명한 문구와 이탈 이유를 기록한다.
- [ ] observe 상태의 자동화에 실제 관측 최소 48시간과 의도적 실패 시험을 더한 뒤 승인/자동 전환을 판단한다. 관측 0건은 성공 증거가 아니다.
- [ ] 베타 모집량, 운영시간, 소개·문의 응답 기준, 안전 사건 대응 담당과 중단 기준을 확정한다.

## 유료 출시 전 외부 게이트

- [ ] 통신사 본인·성인 확인 공급자 LIVE 계약과 미성년/중복/취소/복귀 경로 확인.
- [ ] PG 심사와 실사용 플래그 전 샌드박스 승인·취소·결과 미상 대사 확인.
- [ ] 약관·환불·개인정보 수집/위탁/삭제·광고 문구의 전문가 검토와 실제 화면 대조.

외부 게이트가 열리기 전 **유료 공개 출시 완료로 표시하지 않는다**. 제한된 무료 베타도 실제 신원·성인 확인 보장처럼 아직 검증되지 않은 표현을 쓰지 않고, 모집 범위를 운영 가능한 수준으로 제한한다.
