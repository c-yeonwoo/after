THESIS: 내 연애의 현재 위치와 다음 행동 하나를 즉시 읽는 개인 비서. 같은 크기의 카드 목록과 구분선으로 이어지는 웹 문서를 거부한다.

OWN-WORLD: 코럴 행동색은 유지하되 보랏빛 잉크·옅은 라일락의 비서 영역, 흰 답변 영역을 분리한다. Wanted Sans의 단단한 제목과 넉넉한 본문. 비서 아바타, 말풍선, 액션 도크를 재사용 가능한 브랜드 컴포넌트로 만든다.

STORY: 계정 확인 → 내 비서에게 나를 알려주기 → 공개 전 프로필 검토 → 상태 확인 → 허용된 상대와 대화 준비. 사용자가 확정하기 전에는 상대에게 아무것도 보내지 않는다.

FIRST VIEWPORT: 위에 작은 비서 마크와 명확한 서비스 이름. 그 아래 28px 상태 제목·짧은 맥락을 하나의 비서 발화로 배치. 실제 약속과 안전 조치는 우선순위대로 그 아래, 질문 도크는 보조다. 프로필 질문은 작은 색 라벨, 답변은 들여쓴 독립 면으로 구별한다.

## 제품 경계

첫 릴리스의 비서는 상태 안내·화면 이동·대화 준비 전용이다. 자유 상담이나 자동 실행을 약속하지 않는다. 가입 완료와 소개 자격 완료는 별개이며 서버 권한은 유지한다. 이미 인증된 계정이어도 약관·성인 확인이 미완료이면 해당 단계가 다음 행동이다. 상대 공개 프로필 재조회가 실패하면 준비 내용을 노출하지 않는다.
