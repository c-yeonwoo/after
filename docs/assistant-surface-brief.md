## 제품 경계

### 연속 대화 확장 · 2026-10-25

홈은 동일한 소유자 대화의 최근 3건과 입력을 표시하고, 전체 페이지는 같은 기록을 이어 읽는다. 기본 조회는 최근 20건이며 전체 페이지에서 시간·ID 커서로 이전 기록을 불러온다. 새 봇이나 별도 세션을 만들지 않는다. 전체 보기로 이동할 때 미전송 초안은 브라우저 실행 메모리에서만 전달하며(60초·1회 인계), URL·영구 브라우저 저장소에 남기거나 자동 전송하지 않는다.

서비스 안내도 서버의 결정적 응답으로 같은 기록에 남기며 LLM을 호출하지 않는다. 프로필 반영·일정 처리 완료 기록은 실제 승인·성공 상태로 전환된 서버 트랜잭션에서만 생성한다. 비공개 상담 동의와 chat 기능이 켜진 경우에만 완료 기록을 남기며, 완료 기록은 LLM 문맥에 넣지 않는다.

모델 문맥은 현재 질문, 최근 완료된 대화 최대 6건, 사용자가 승인한 유효 기억(기억 기능 ON일 때)으로 제한한다. 전체 기록을 무한히 기억하거나 자동 요약·장기 기억으로 축적하지 않는다. 기록은 최대 30일 보관하며 홈과 전체 페이지는 같은 소유자·동의·보관·삭제 권한을 적용한다. 기록 삭제·전체 삭제·동의 철회를 유지하고, 기능 OFF여도 기존 기록 확인과 삭제는 가능하다.

상태·프로필·일정·도움 요청은 기존 규칙과 서버 상태로 안내한다. 기능이 켜지고 동의한 경우 자유 질문도 홈 입력에서 같은 대화에 명시적으로 전송하고 전체 페이지에서 이어간다. 기능 확인 중에는 미전송 질문을 지우거나 자동 전송하지 않는다. 가입 완료와 소개 자격 완료는 별개이며 서버 권한을 유지한다. 인증된 계정이어도 약관·성인 확인이 미완료이면 해당 단계가 다음 행동이다. 상대 공개 프로필 재조회가 실패하면 준비 내용을 노출하지 않는다.

## 2~4단계 확장 계약

비공개 상담은 발화/답변 면, 승인 기억은 원문과 승인 행동, 일정은 불변 초안과 명확한 전송 버튼으로 구별한다. 기억과 대화 삭제에 바로 접근할 수 있다. 대화 준비는 공개 근거에 기반한 만남 팁이며 실제 대화 역할극은 제외한다. 44px 제어·안전영역·키보드 공간·건별 승인·서버 권한을 유지한다. 상담·기억·일정의 운영 기능 플래그는 이번 외형 개편으로 켜지지 않는다.

## 가입·프로필·소개·결제·일정 안내 확장

홈 입력과 비공개 상담은 같은 결정적 의도 라우터를 사용하고, 가입·프로필·소개·티켓·일정 등 서비스 FAQ는 정해진 근거 문구와 기존 화면으로 안내한다. 서비스 FAQ에는 LLM을 호출하지 않으며 서버 경로에도 같은 판정을 적용한다. 안내와 이동은 저장·호감 전송·티켓 사용·결제·일정 확정을 실행하지 않는다. 각 기존 화면에서 내용을 확인하고 사용자가 명시적으로 승인해야 한다. 상담·기억·일정·매니저 소개·프로필 수정의 운영 플래그는 OFF를 유지하고, 비활성 기능은 기존 수동 동선으로 안내한다. `GuideNote`·`StepShell`의 비서 발화는 기존 `AssistantMark`를 사용하며, `AssistantActions`는 기존 제안 버튼 스타일과 44px 제어를 재사용한다. 승인된 흰 표면·핑크 테두리 토큰을 따르며 원본 캐릭터·Wanted Sans·기존 모션은 유지한다.

## 매니저 소개·프로필 수정

상대의 공개 권한과 명시적 동의가 있을 때만 소개 설명을 준비한다. 매니저의 해석과 회원이 직접 적은 원문 근거를 구분하며, 적합도 점수나 보장 문구는 넣지 않는다. 기능 OFF이면 기존 프로필 읽기를 유지하고, 권한 확인 실패에는 설명을 숨긴다.

홈에서 프로필 수정 의도를 알아차려도 자동 생성하거나 공개하지 않는다. 수정 요청과 AI 처리 동의를 확인한 뒤 초안을 만들고, 현재 문장과 수정안을 비교해 사용자가 승인해야 저장한다. 초안은 비공개이고 사진·기본 정보·비공개 선호는 건드리지 않는다. 생성 실패에는 기존 프로필이 남으며, 수동 편집 동선도 유지한다.
