## 제품 경계

상태·프로필·일정·도움 요청은 기존 규칙과 서버 상태로 안내한다. 자유 질문은 기능이 켜져 있을 때 비공개 상담의 동의·전송 화면으로 이어진다. 홈 질문은 URL·영구 브라우저 저장소에 남기지 않으며, 기능 확인 중에는 지우거나 자동 전송하지 않는다. 가입 완료와 소개 자격 완료는 별개이고 서버 권한을 유지한다. 이미 인증된 계정이어도 약관·성인 확인이 미완료이면 해당 단계가 다음 행동이다. 상대 공개 프로필 재조회가 실패하면 준비 내용을 노출하지 않는다.

## 2~4단계 확장 계약

비공개 상담은 발화/답변 면, 승인 기억은 원문과 승인 행동, 일정은 불변 초안과 명확한 전송 버튼으로 구별한다. 기억과 대화 삭제에 바로 접근할 수 있다. 대화 준비는 공개 근거에 기반한 만남 팁이며 실제 대화 역할극은 제외한다. 44px 제어·안전영역·키보드 공간·건별 승인·서버 권한을 유지한다. 상담·기억·일정의 운영 기능 플래그는 이번 외형 개편으로 켜지지 않는다.

## 가입·프로필·소개·결제·일정 안내 확장

홈 입력과 비공개 상담은 같은 결정적 의도 라우터를 사용하고, 가입·프로필·소개·티켓·일정 등 서비스 FAQ는 정해진 근거 문구와 기존 화면으로 안내한다. 서비스 FAQ에는 LLM을 호출하지 않으며 서버 경로에도 같은 판정을 적용한다. 안내와 이동은 저장·호감 전송·티켓 사용·결제·일정 확정을 실행하지 않는다. 각 기존 화면에서 내용을 확인하고 사용자가 명시적으로 승인해야 한다. 상담·기억·일정 운영 플래그는 OFF를 유지하고, 비활성 기능은 기존 수동 동선으로 안내한다. `GuideNote`·`StepShell`의 비서 발화는 기존 `AssistantMark`를 사용하며, `AssistantActions`는 기존 제안 버튼 스타일과 44px 제어를 재사용한다. Orange Companion 토큰·원본 캐릭터·Wanted Sans·모션은 추가하거나 변경하지 않는다.
