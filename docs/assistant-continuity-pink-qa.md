# 화이트·핑크 디자인과 비서 연속 대화 검증

2026-10-25. 사용자가 승인한 시안은 흰 배경, `#EF8798` CTA 테두리, `#F2B1B5` 작은 선택 포인트, `#FFF2F6` 사용자 말풍선과 중립 회색 글씨다. Fresh Pink 채움 버튼은 사용하지 않는다. 디자인 토큰과 컴포넌트 계약은 `DESIGN.md`와 `.impeccable/design.json`에 반영했다.

## 반영 내용

- 공통 버튼과 직접 작성된 주요 행동 링크를 같은 테두리 규칙으로 통일했다. 진행 막대·입력 커서·아이콘·체크 표시에는 별도 고대비 잉크를 사용한다. 승인 캐릭터·폰트·안전영역·두 탭은 유지한다.
- 홈 최근 3건과 전체 대화가 같은 소유자 전용 기록을 읽는다. 전체 대화는 기본 20건과 이전 기록 커서를 제공하며 새 기록이 도착해도 펼쳐 읽던 기록을 유지한다.
- 홈에서 직접 전송하고 전체 화면에서도 이어 쓴다. 미전송 초안은 기존 60초 일회성 메모리 인계만 사용하고 자동 전송하거나 URL에 넣지 않는다. 화면 전환 중 입력을 잠가 나가는 화면과 새 화면 사이의 입력 경쟁을 막는다.
- 서비스 안내도 결정적 서버 응답으로 기록하며 모델을 사용하지 않는다. 프로필 반영·일정 처리 완료는 서버 성공 트랜잭션에서만 기록하고 중복 처리하지 않는다. 완료 안내를 LLM의 회원 발언으로 사용하지 않는다.
- 전체 대화 기록과 모델 입력은 다르다. 모델에는 최근 완료 대화 최대 6건과 승인된 유효 기억만 사용한다. 자동 장기 기억·요약을 추가하지 않는다. 보관 30일, 삭제·동의 철회·revision 검사를 유지한다.

## 확인 범위

이번 최종 회귀 검사에는 합성 회원과 모의 결제만 사용했다. 서비스 질문은 `ai_runs` 생성 0건을 확인하고, 브라우저의 예상 밖 자유 질문은 공급자 호출 전에 차단했다. 실제 LLM 생성문 품질의 기존 검증은 `concierge-llm-local-qa.md`에 별도로 남아 있다. 이번 결과를 새로운 모델 품질 평가나 실결제·실제 통신사 인증·실기기 키보드/스크린리더 검증으로 확대해 해석하지 않는다. 운영 기능을 켜는 결정은 이 변경에 포함하지 않는다.

## 공통 영역 캐시 보완 (2026-10-25)

- 비서 캐릭터를 `src/assets/concierge/`에서 import한다. 배포 빌드의 내용 해시 URL과 기존 `/assets/*`의 1년 immutable 정책을 사용하며, 이미지 변경 시 URL도 바뀐다. 원본 WebP 바이트와 외형은 그대로다. 생성 프롬프트는 소스에 보존하고 공개 디렉터리에서는 제외했다.
- 고정 인사·빠른 도움·안내 문구는 기존 번들 내 결정적 템플릿을 재사용한다. 별도 조회나 LLM 생성은 없다. 현재 시각·회원 상태에 따라 조립되는 문구 자체를 전역 캐시하지 않는다.
- 비서 기능 UI 스냅샷은 계정별 QueryClient 키로 60초 재사용·활성 화면에서 60초 간격 갱신한다. 중첩된 기능 조회 구독을 제거했다. 서버의 실행 시점 권한·동의 검사는 바꾸지 않았다.
- 결제 표시 설정도 브라우저 메모리에 60초 보관하고 동시 요청을 합친다. SSR은 캐시를 우회한다. 오류는 성공값으로 캐시하지 않는다. 로그아웃·계정 변경·관리자 결제 모드 변경 성공 시 초기화하며, 늦은 응답이 새 캐시를 덮어쓰지 못한다. 주문·발급은 여전히 서버의 실제 설정으로 판정한다.
- 개인 대화·약속·수정 초안·잔액과 개인정보는 공용 캐시에 넣지 않는다. 기존 개인 상태 갱신·삭제 검증도 유지한다. localStorage·Service Worker·공유 CDN 응답 캐시는 추가하지 않았다.
- `npm run check`, 캐시 TTL/동시 요청/실패 복구/계정 초기화 경쟁 검사, Chromium·WebKit의 비서 API/모바일·다크·기억 동의·삭제 검사가 통과했다. 홈→전체 대화→홈 이동에서 비서 기능·결제 표시 설정 조회 각각 1회임을 확인했다.
- 로컬 Wrangler에서 실제 배포 빌드의 남녀 이미지 모두 200·1년 immutable 헤더·원본 바이트 일치를 확인했다. HTTP 라우팅 모킹 없는 Chromium에서 여성 이미지 최초 전송 52,820바이트, 재조회 전송 0바이트를 확인했다. 일반 브라우저 회귀 스크립트는 Playwright 라우팅이 HTTP 캐시를 비활성화하므로 해당 검사와 분리했다. 운영 CDN의 배포 후 헤더는 별도 확인 대상이다.
- 후속 릴리스 확인에서 이전 main CI가 삭제된 여성 홈 문구를 기다리는 것을 발견했다. 현재 대기 안내·소개 메뉴 검증으로 갱신하고, 기본 통합 검사도 비서 실험 플래그 5개를 보관·일시 분리·복구하도록 맞췄다. 변경 후 Chromium 전체 사이클 47개 통과, 실패 0개 (`/tmp/after-full-cycle-95459742/report.json`). 가입·호감/거절·모의 결제·약속 변경·실시간 대화·넛지·취소/티켓 복구·자정 후기·운영 큐·MFA 재인증을 포함한다. 이 결과는 운영 배포 완료나 실결제 검증이 아니다.
