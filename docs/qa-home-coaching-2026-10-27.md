# 채팅 중심 홈과 프로필 코칭 — 2026-10-27

## 변경 범위

- 홈에서 새 소개 수신 스위치·만남 가능 시간 설정 제거. 기존 `나 → 환경설정` 및 `나 → 만남 가능 시간` 진입과 기능은 유지한다.
- 인사와 진행 상황 다음에 비서 대화를 배치한다. 승인된 캐릭터는 바꾸지 않는다.
- 옅은 로즈 비서 말풍선, 구분되는 사용자 핑크 말풍선, 면적 전체가 채워지는 선택 탭. 흰 캔버스와 다크모드 유지.
- 질문 예시와 입력에 맞는 로컬 추천. 선택은 초안 채우기만 하며 직접 전송해야 모델을 호출한다.
- 홈 입력창 고정, 직접 전송한 새 답변만 스크롤 추적. 작은 키보드 화면에서는 추천을 접고 입력·전송을 우선한다.
- 내 프로필의 기존 요약을 원문 인용·표현 개선 안내로 교체한다. 상담 활성화 시 `비서에게 코칭받기`가 초안을 넘긴다.
- 실제 코칭은 서버에서 본인 공개 문장만 읽고 `살릴 매력 → 다듬을 표현 → 이렇게 써보세요`로 답한다. 프로필 자동 수정/저장 없음.
- 같은 코칭 주제의 후속 질문도 현재 원문을 다시 읽는다. 비공개 인터뷰, 사진, 성별, 상대방 데이터는 이 코칭 컨텍스트에 포함하지 않는다.
- 광고·큐레이션 배너는 추가하지 않았다. 향후에도 대화 입력과 긴급 약속 행동을 가리지 않는 별도 위치가 필요하다.

### 실LLM 실패를 숨기지 않은 기록

v4 두 건은 품질 게이트에서 거절됐다. 첫 건은 원인을 분리하지 못했고, 두 번째는 `ungrounded`였다. 별도 합성 진단에서 원문에 없는 연락 응답 약속을 덧붙이는 출력을 발견했다. 원문 밖의 시간·이유·감정을 질문으로 돌리도록 지침을 강화했고, v5 두 건은 원문과 음주·낯가림·업무 중 연락 경계를 유지했다. 실패 영수증을 지우거나 동일 요청을 재전송하지 않았다. 합성 계정은 종료 후 삭제했다.

- 실패 영수증: `/tmp/after-profile-coach-live-v4/receipts/`
- 합성 진단: `/tmp/after-profile-coach-diagnostic-v4/`
- 성공 출력·토큰: `/tmp/after-profile-coach-live-v5/results.json`
- 화면/접근성 결과: `/tmp/after-home-coaching-final/`

두 사례 성공은 모든 입력의 품질 보장이 아니다. 품질 실패 시 답변을 공개하거나 프로필에 저장하지 않고 오류로 끝낸다. 새 유료 호출이 필요한 재시도는 자동 실행하지 않는다. 사용자 피드백과 실패율을 별도로 관찰해야 한다.

## 미확인 / 변경하지 않은 범위

추가 전체 브라우저 회귀(`AFTER_TEST_PORT=4198 npm run test:browser-e2e`)도 통과했다. 가입·베타/인증 필수 분기·모의 유료/베타 소개와 만남·가능 시간·약속 도움·인터뷰·어드민을 포함한다. 제거한 홈 설정을 찾던 기존 테스트는 `나 → 환경설정`의 소개 중지/재개 및 DB 반영 확인으로 이전했다. 기존 4174 서버는 종료하지 않고 별도 포트를 사용했다.

- 실제 iPhone/Android 네이티브 키보드: 이번에는 브라우저 및 높이 시뮬레이션이며 실기기 확인은 별도다.
- 운영 비서·기억·일정 기능, 통신사 인증 및 실결제 플래그는 켜지 않았다.
- 실회원 데이터, 실제 결제·취소·외부 알림·SNS 발송 없음.
- 출시 전 사용자의 기존 로컬 계정으로 대화 전송 → 코칭 후속 질문 → 수정안 직접 확인 흐름을 체감 확인한다.
