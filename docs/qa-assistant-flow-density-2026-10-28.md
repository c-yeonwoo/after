# 비서 화면 밀도·실제 로컬 흐름 검증

기준일: 2026-10-28 (Asia/Seoul). 운영 기능 설정·운영 회원 데이터는 변경하지 않았다.

## 변경

- 홈 진행 제목의 별도 색 면을 제거하고, 비서 식별 줄에 전체 대화 진입점을 통합했다.
- 홈 빠른 메뉴는 소개 확인·내 프로필 수정·일정 정리 3개로 줄였다. 전체 상담과 기억 관리는 별도 비서 화면에서 유지한다.
- 추천 질문은 밝은 테두리 표면, 저장된 비서 답변은 열린 본문으로 구분한다. 사용자 발화의 로즈 말풍선과 약속 카드 강조는 유지한다.
- 프로필 다듬기에 현재 공개 글 미리보기와 요청 예시를 제공한다. 예시는 입력만 채우고 API를 호출하지 않는다.
- 프로필 수정 버튼은 하단에, 명시적 AI 처리 동의는 스크롤 본문에 둔다. 대기·검토 중 빈 푸터는 숨긴다.
- 상대 채팅에 개인 비서 연결을 제공한다. 공유 메시지나 상대 식별정보를 개인 비서에게 전달하지 않는다. 서버 기능 플래그에 따라 숨긴다.

독립 리뷰에서 처음 발견한 P2는 작은 네이티브 키보드 프레임에서 고정 동의 영역이 입력칸을 가리는 문제였다. 동의를 본문으로 이동한 뒤 같은 조건에서 재검증했다. 미해결 P1/P2 없음. 실기기 키보드·실결제·통신사 인증·외부 알림은 이번 검증에 포함하지 않는다.

## 직접 확인

[계정·따라 할 순서](assistant-manual-cycle.md). `5191`은 처음부터 진행할 계정, `5192`는 약속·채팅까지 완료된 시연 커플이다. 두 서버 모두 loopback 전용이다. 일반 탭은 세션을 공유하므로 남녀는 서로 다른 브라우저/시크릿 창을 사용한다.

전후 캡처와 실제 흐름 갤러리는 로컬 시각화 폴더의 `after-flow-tour-2026-10-28/preview.html`에 있다. 홈 전후는 동일 합성 화면, 프로필 수정 전후는 동일 로컬 계정이다. 새 소개 도착 캡처는 UI 정리 전 초기 촬영임을 갤러리에 표시했다.

운영의 상담·기억·일정 실행을 켜는 변경은 포함하지 않는다. 로컬에서 자유 질문·프로필 초안 생성을 명시적으로 전송하면 설정된 모델 API 비용이 발생할 수 있다.
