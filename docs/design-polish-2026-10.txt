애프터 · 여백, 모션, SNS 형식 개선
2026-10-18

기존 Evening 팔레트와 워드마크를 이어가는 마감 작업.
Impeccable 플러그인4.3.1의 polish/layout/animate 지침과 Motion 공식 스킬의 CSS/React best practices를 적용.
Motion의 자체 포함 지침을 사용했으며 별도 Motion MCP 연결이나 유료 도구는 추가하지 않았다.
추가 프런트엔드 패키지는 없다.

공간과 읽기
- 랜딩도 가입/앱과 같은 좌우20px 기준선을 사용.
- 랜딩의 중복 키커를 줄이고, 기존 가상 소개를 실제 제품처럼 문답형으로 표시.
- 가입 본문 위24px, 제목 아래 설명10px, 입력 그룹 전24px로 정보 묶음 정리.
- 가입 제목은320px에서도 단어 단위로 줄바꿈하고 24~28px 범위에서 조정.
- 프로필 질문 아래 답8px, 섹션 내부 상단16px. 답변 행간1.6.
- 일반 확인창/모달은 모바일 좌우20px 이상, 최대390px, 최대 높이85dvh에서 내부 스크롤.
- 확인창의 제목/본문은 왼쪽 정렬, 버튼 간격8px. 다크에서도 배경을 어둡게 하는 scrim 토큰 사용.

모션의 역할
- 랜딩 사진은420ms의 한 번뿐인 짧은 마스크 전개.
- 질문/화면 변경은180ms,4px 이동. 입력 상태를 유지한 채 DOM의 표시만 바꿈.
- 대화방(fill)은 본문 전환 효과에서 제외해 입력 영역을 움직이지 않음.
- 버튼과 칩은140ms 색/눌림 피드백, 토글은150ms.
- 확인창은200ms 진입/140ms 종료,98% 크기에서 정착.
- 모션 줄이기 설정에서는 공간 이동/사진 전개/확인창 효과를 제거.
- Radix 상태 선택자보다 모션 줄이기 규칙이 우선하도록 확인. 확인창 크기/배경에 암묵적 transition-all이 생기지 않도록 차단.
- 페이지를 스크롤할 때마다 반복되는 등장 효과나 무한 루프는 넣지 않음.

- 실제 화면은 공개 랜딩의 가상 프로필만 캡처. 회원 개인정보 없음.
- 영상은 답변 장면의 충분한 읽기 시간을 위해3/7/8/4초로 구성, 각 전환0.5초.
- 새 콘셉트 사진 생성 호출 없이 기존 브랜드 사진과 타이포/실제 화면으로 제작.
- 렌더 소스, 캡션, 대체 텍스트, 로컬 미리보기 제공. 게시/광고는 미실행.
