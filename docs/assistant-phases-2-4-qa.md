- AI는 상담/초안만 제공한다. 결제·환불·거절·신고·메시지 발송을 실행하는 도구를 갖지 않는다.

- MBTI는 궁합·감정·성격 추정의 근거로 쓰지 않는다. 공개한 실제 선호를 우선하고, 유형이 없어도 조언 가능해야 한다.

## 구현과 검증 기록 · 2026-10-24

### 제공하는 범위

- 개인 상담: 원문 전달 동의, 본인 전용 최근 대화, 직접 승인한 선호만 기억. AI가 답변했다고 자동으로 기억하지 않는다.
- 일정 비서: 기존 만남의 가능한 시간 전달 / 제안 수락 / 시간·장소 확정 / 변경 요청을 불변 초안으로 만든다. 건별 승인 후 기존 권한과 조율 절차를 실행한다. 자연어로 임의 일정을 추측하거나 비서끼리 자율 확정하지 않는다.
- 만남 전 조언: 상대가 공개한 내용에서 질문과 후속 질문, 시작 소재·부담을 줄일 표현·대화 속도 팁을 만든다. MBTI별 성격이나 상대 감정을 단정하지 않는다. 대화 역할극은 제외했다.
- 회고: 후기 뒤 기억 관리 진입만 제공한다. 후기 원문을 AI에 자동 전송하거나 선호로 자동 저장하지 않는다.
- 운영: MFA 권한을 확인한 관리자에게 대기·지연·성공 수, AI 사용량, 정리 작업 상태만 보여준다. 상담·기억·일정 초안 원문은 보이지 않는다.

### 검수에서 수정한 문제

1. 삭제 직전 열어 둔 기억 승인 창이나 늦은 HTTP 요청이 삭제된 맥락을 복구하지 못하도록 승인 시점 privacy revision을 서버에서 비교한다.
2. AI 실패가 확정된 요청 ID는 재시도 시 교체하고, 네트워크 결과가 불명확하면 같은 ID로 영수증을 먼저 확인한다.
3. 오래된 pending 응답을 실패로 정규화해 재시도 UI가 영구 대기하지 않게 했다.
4. 일정 초안이 있으면 입력 폼을 접고 승인 요약을 먼저 보여준다. 상대 정보는 입력 제목 아래 배치한다.
5. 과거/허용 범위 밖 날짜·변경 불가능한 시각·장소명 누락은 전송 전에 구체적으로 안내한다. 성공 뒤에는 영수증을 우선하고, 새 입력은 '일정 다시 준비하기'로 명시적으로 연다.

보안 코드 검수는 위 경합·재시도 수정을 재확인한 뒤 승인했다. Impeccable 전용 역할이 제공되지 않아 독립 일반 에이전트에 해당 검수·문서화 계약을 적용했다. 기존 Sunset Companion 토큰·서체·모션을 유지했고 DESIGN.md와 sidecar를 불필요하게 다시 쓰지 않았다. 기존 Gowun Batang 예외는 이번 변경에서 추가하거나 확대하지 않았다.

독립 디자인 검수는 상대 이름 eyebrow 한 건을 `fix`로 지적했고, 제목 아래로 옮긴 뒤 모바일·데스크톱·다크·요청 완료 화면 재캡처에서 해당 수정의 `disposition: ship`을 받았다. 이는 해당 수정의 최종 판정이며 모든 환경의 완전성을 뜻하지 않는다. 새 ignore/suppression은 추가하지 않았다.

### 운영에서 아직 켜지 않는 항목

- `assistant_chat_enabled`, `assistant_memory_enabled`, `assistant_schedule_enabled`: migration 기본값 모두 false. 이번 릴리스로 활성화하지 않는다.
- 활성화 전 별도 확인: 처리 고지·동의/제공자 조건, 운영 삭제/철회·장애복구, 실기기 입력·키보드, 제한된 참가자 조언 품질 확인.
- 현재 공개 개인정보 처리방침과 가입 동의 버전은 변경하지 않았다. 비활성 기능의 고지를 같은 버전으로 조용히 덧붙이지 않는다. 아래 초안을 검토한 뒤 공개 버전·서버 가입 동의 버전을 함께 갱신하는 릴리스와 활성화를 별도로 결정한다.
- 실결제·통신사 인증·카카오 발송·실회원 일정 실행은 이번 합성 검증의 통과 항목이 아니다.
- 기존 공개 프로필 대화 준비 기능의 짧은 맞춤 팁만 기존 동의·접근 권한 안에서 확장한다. 상담과 기억 활성화를 전제로 하지 않는다.

### 활성화 전 검토할 고지 초안 · 미게시

개인 비서 상담·기억 기능은 별도 활성화 및 동의 후 제공됩니다. 이용 시 직접 입력한 상담 내용, 최근 상담 맥락과 별도 승인한 선호 기억을 Anthropic(미국)에 전송해 답변을 만듭니다. 상대와 주고받은 채팅은 자동으로 가져오지 않습니다. 이름·연락처·민감한 정보를 상담에 적지 마세요. 서비스의 상담 기록은 30일, 승인 기억은 90일 뒤 만료되어 조회·답변 생성에서 제외되며 시간당 정리 작업으로 삭제됩니다. 설정에서 직접 삭제하거나 상담 동의를 철회할 수 있습니다. 기억 삭제·수정 시 해당 내용이 남지 않도록 상담 맥락도 삭제합니다. 상담·기억 원문을 운영 대시보드에 표시하지 않습니다. 일정 비서의 승인 초안과 처리 결과는 30일 보관하며, 기존 약속 기록은 별도 보관 기준을 따릅니다.
