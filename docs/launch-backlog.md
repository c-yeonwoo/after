## 외부 의존 — 공급자/전문가 확정 뒤 진행

- **본인인증**: 통신사 계약/키·실개통, 생년월일·성별·중복 CI 등 응답·실패/탈퇴 검증. 베타의 SMS 소유 확인+입력 생일을 공인 성인/실명/재직 확인으로 표현하지 않는다.
- **PG 실결제·실환불**: 주문 생성 → 승인 웹훅 검증 → 티켓 발급 → 거절/만료/탈퇴
  환불의 멱등성, 공급자 실수신·정산 증빙. 내부 주문/티켓 대역 검증은 실제 카드 승인·취소가 아니다. 완료 전 결제 OFF.
- **카카오**: After 채널 생성은 대표 확인(검색용 ID **애프터선셋**). 비즈니스/업종·템플릿 승인, 실제 채널 ID·발송 작업자·실수신 검증은 후속. [도입 체크리스트](./kakao-notifications-rollout.md)
- **법률·사업자 검토**: 통신판매/전자상거래 표시, 청약철회·환불, 개인정보 처리방침,
  위치·민감정보 취급, 미성년자 차단, 신고/제재 고지, 사업자 정보와 고객문의 채널을
  변호사/노무·세무 전문가와 확인. 확인 전에는 존재하지 않는 사업자 정보나 보장을
  화면에 쓰지 않는다.

## 이번 MVP에서 확정한 운영 기준

- **노쇼는 사람 검토**: 인정·부인·24시간 무응답을 모두 운영자 검토 큐로 보낸다.
  무응답이나 한 번의 탭만으로 영구 제한하지 않는다. 운영자는 양쪽 후기와 일정 기록을
  확인하고 사유를 남겨 확정·기각한다. 24시간은 자동 처벌 시점이 아니라 검토 SLA다.
- **안전 SLA**: 콘텐츠 신고와 노쇼 신고는 24시간 안에 1차 확인한다. 이용 제한 판정은
  근거를 기록하고, 공개 문의 주소로 이의 제기를 받는다. 긴급 범죄·신체 위험은 앱이
  해결한다고 약속하지 않고 112 등 관계 기관에 즉시 연락하도록 안내한다.
- **운영 연락**: 별도 선택 동의 없는 회원에게 인증용 번호로 연락하지 않는다. 앱 문의로 확인한다. 동의해도 상대에게 번호 미공개, 운영 메모에 전화번호 복사 금지.
- **관제**: 매일 오전/오후, 약속 D-4h/D-2h 작업함 확인. 약속 당일 확인할 운영자가 없으면 새 약속을 받지 않는다.

## 출시 직전 사람 확인

- 실제 iPhone/Safari·Android/Chrome에서 사진·키보드·뒤로가기·세션 재진입·작은 화면. WebKit 자동화는 실제 기기가 아니다.
- 실제 회사 메일 가입·SMS 코드 수신 1회. 대역 테스트를 공급자 실수신으로 세지 않는다.
- 대표 관리자 MFA 등록·복구수단 직접 확인. 테스트 토큰 통과는 대표 MFA 등록 증거가 아니다.
- 최종 AI 합성 입력 10회 성공·작성자 5–8명 만족도/허구 검토. 추가 실제 생성 1회 성공(9.64초), 나머지는 정상 일일 한도로 보류. 쿼터 우회 안 함.
- 실제 운영 48시간 큐 관찰 후 자동화 확대. 현재 웹은 앱을 닫으면 카카오/메일 알림이 오지 않는다. 전송·수신·앱 열람을 혼동하지 않는다.
- PG·본인인증·법률 항목이 완료되기 전에는 유료 공개 모집 대신 제한된 무료/수동 POC로 운영
