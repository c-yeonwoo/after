# 가입 인증 모드·KCP 복구 검증 — 2026-10-26

## 구현 범위

- 개발 우회는 `VITE_DEV_AUTH_BYPASS=true` + 개발 빌드 + loopback backend, Edge의 `DEV_AUTH_BYPASS=true` + 정확한 로컬 backend에서만 허용한다. 기본 OFF, 비밀키 누락은 우회 조건이 아니다.
- 개발 회사메일 가입은 Edge의 로컬 모드 확인을 거친다. 휴대폰은 명시적 bypass 요청으로만 합성 코드를 받아 정상 RPC로 소비하고 자동으로 다음 화면에 간다. 실제 SMS를 보내거나 통신사 본인인증 기록을 위조하지 않는다.
- 신규/기존 KCP 검증기는 ID·LIVE 채널·성별·생년월일·번호·DI를 동일하게 확인한다. 기존 회원의 성별 불일치는 자동 수정하지 않고 고객센터로 안내한다.
- 저장된 인증 완료 응답 유실은 동일 소유자·인증 ID 영수증으로 복구한다. 공급자 조회는 12초 제한, 새 인증 시작 전 미완료 ID를 먼저 재확인한다.
- 결제 공급자/상품/가격/정책, 운영 인증·결제·비서 플래그는 바꾸지 않았다.

## 미검증·외부 게이트

- PortOne/KCP 계약은 심사 중. 실제 LIVE 인증창, 실제 성인/미성년 결과, 취소·휴대폰 브라우저 복귀, 실계약 채널 필드 제공 여부는 키 발급 후 검증해야 한다.
- 네이티브 앱 WebView ↔ 외부 인증 앱 복귀는 이번 웹 베타 범위가 아니다. 기존 안내·차단 유지.
- 운영 `app_settings.identity_required`는 별도 서버 권위 게이트다. 프런트 플래그만으로 대체하거나 키 저장과 동시에 자동으로 켜지 않는다. 기존 회원 전환까지 확인한 뒤 운영자가 활성화한다.
- 토스 실결제/취소, 법률 검토, 카카오 발송은 이번 인증 변경의 완료 근거에 포함하지 않는다.

사용/전환 값은 [본인인증 롤아웃](../carrier-identity-rollout.md)을 따른다.
