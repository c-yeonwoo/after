# 애프터 매니저 화면과 개인화 검증

2026-10-28 기준. UI 및 대화 보관 변경은 로컬 검증을 통과했지만, 상대 소개 LLM은 실제 호출 4회가 사실성 검증에서 실패했다. 운영의 상담·기억·일정·소개 설명·프로필 수정 플래그 5개는 모두 OFF이며 활성화 대상이 아니다.

## 반영 내용

- 이름을 **애프터 매니저**로 통일했다. AI임을 숨기지 않되 집사·비서·애프터 AI를 번갈아 쓰지 않는다.
- 새 소개는 옅은 브랜드 표면과 테두리로 식별한다. 홈의 진행 영역과 대화 시작 사이를 구분한다. 기존 캐릭터·색상·탭·성별별 흐름은 유지한다.
- 상세 프로필은 한 장의 테두리와 16~24px 안쪽 여백을 가진 읽기 표면이다. AI 설명이 통과한 경우 원문 인용을 하이라이트로 표시하고, 상대 관찰·두 사람의 접점·함께 알아볼 점을 구분한다. 인용은 생성한 문장이 아닌 실제 공개 답변이어야 한다.
- 소개 설명의 별도 체크박스를 없애고 **매니저와 함께 읽기** 버튼 및 인접 처리 안내로 바꿨다. 페이지 방문만으로 모델을 호출하지 않는다. 이 버튼이 상대방을 대신한 법적 동의라는 의미는 아니다. 외부 처리의 적법 근거·고지는 별도 검토 대상이다.
- **공개 프로필로 준비하기**를 **대화 주제 받아보기**로 바꿨다. 프로필을 다시 만들라는 뜻이 아니다.
- 매번 **이 내용 기억하기**를 누르는 흐름을 제거했다. 상담은 하나의 기록으로 이어지고, 기존 저장 선호의 열람·수정·삭제는 대화 설정에 남겼다.

## 개인화와 보관 경계

일반 상담에도 서버에서 본인의 나이·직업·소개 활동 지역·MBTI·공개 글을 읽어 전달한다. 이름·생년월일 원문·전화번호·회사 이메일·사진은 전달하지 않는다. 소개 활동 지역을 거주지로 해석하지 않고, MBTI를 성격 진단으로 단정하거나 없는 사주 정보를 만들어내지 않는다.

한 번의 호출에는 최근 완료 대화 6개와 질문에 관련된 이전 사용자 발언 최대 4개를 제공한다. 과거 AI 조언은 오래된 사용자 사실로 추출하지 않는다. 전체 기록을 매번 보내는 구조도, 모든 과거를 완벽하게 기억한다고 보장하는 구조도 아니다.

새 처리 안내 `manager-continuity-v2`에 명시적으로 동의한 사용자의 기록만 초기화·철회·탈퇴 전까지 보관한다. 구형 boolean 동의 RPC는 새 안내를 수락할 수 없고 기존 30일 기록을 자동 연장하지 않는다. 새 동의 없이도 기존 기록을 읽고 지울 수 있다. 만료된 기록을 복구하지 않는다. 별도로 저장된 기존 선호는 원래의 90일 수명을 유지한다.

본인·세션·privacy revision을 검사하고, 초기화/철회/프로필 변경 뒤 늦게 도착한 응답은 폐기한다. 실패한 소개 설명은 표시하지 않으며, AI 설명이 아니라고 밝힌 기존 공개 프로필 기반 대화 소재로 전환한다. 실패 후 자동 유료 재시도는 없다.

## 소개 LLM 차단 항목

운영 코드와 같은 endpoint에서 low 추론 3회, medium 추론 1회가 모두 실패했다. 추론량 상향이 해결책이라는 증거가 없어 low로 되돌렸으며 모델은 기존 Sonnet 설정을 유지한다. 모델 검증 기준을 완화하거나 실패를 성공으로 바꾸지 않았다.

별도의 합성 초안 생성 1회와 그 초안 검증 1회에서는 읽을 만한 결과가 나왔지만, 이는 endpoint의 end-to-end 성공이 아니다. 단일 진단 결과만으로 원인을 확정하지 않는다. 다음 단계는 합성 자료만 사용하는 평가 도구에서 생성·검증 입력/출력의 정확한 실패 문장을 함께 포착해 원인부터 구분하는 것이다. 운영 회원 원문·실패 초안을 로그에 남기는 방법은 사용하지 않는다.

이번 실호출은 endpoint 5개 작업(상담 1 + 소개 4, 각 기존 검증 호출 포함) 및 별도 합성 진단 호출 2회였다. 실패 영수증은 `/tmp/after-personal-manager-live-v6`에 보존했다. 앱 내 usage 합계는 입력 22,184 / 출력 3,751 토큰이며, 별도 진단 입력 3,688 / 출력 2,249 토큰은 이 합계 밖이다. 통화 비용으로 환산하거나 모델 단가를 추정하지 않는다.

테스트용으로 이번에 생성한 계정 2개만 정리했다. 기존 manual/tour 계정·진행·운영 데이터는 삭제하지 않았다.

## 로컬 확인

[기존 계정과 순서](../assistant-manual-cycle.md)를 그대로 쓴다. `http://127.0.0.1:5191/home`을 새로고침하면 변경 UI가 반영된다. 홈과 전체 대화는 같은 기록이다. 새 보관 안내는 처음 한 번 확인해야 하며 기존 기록 삭제를 원하지 않으면 초기화 버튼을 누르지 않는다.

상대 소개 AI는 아직 품질 검증 완료가 아니다. 테스트 중 설명이 준비되지 않으면 공개 프로필 기반 내용으로 전환되는지 확인한다. 반복 생성으로 품질을 확인하려고 하지 않는다. 운영 기능 활성화·실결제·통신사 인증·카카오 알림은 이번 변경에 포함하지 않는다.
