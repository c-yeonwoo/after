## 변경 범위

이메일·SMS 베타 가입, 기존 남녀 소개 순서, 모의 결제/티켓, 약속·채팅·후기를 유지한다. 운영 매니저 기능 5개, 결제, 통신사 본인인증 플래그는 이번 변경으로 켜지 않는다. 회사 이메일 소유 확인을 재직 인증으로 표시하지 않는다.

초안의 사진 파일은 기존 비공개 저장소에 있고 초안에는 경로만 저장한다. 로컬 미전송 초안은 7일 만료 시 접근 때 제거한다. 서버 초안은 가입 완료·계정 비활성화 시 제거한다. 비밀번호·인증코드는 저장하지 않는다. 다중 기기의 충돌은 조용히 덮어쓰지 않는다.

## AI 예산 계약

대표 승인: **KST 하루 3,000원 / 달력 월 50,000원**. 설정 테이블 제약도 이 상한보다 높게 올릴 수 없다.

- 서비스 전체 예산이며 상담뿐 아니라 프로필 생성·수정·소개 해설·대화 준비·운영자 설명 생성까지 포함한다.
- 트랜잭션 잠금으로 동시 호출을 합산한다. 사용자별 기존 횟수 제한도 유지한다.
- 모델별 입력/출력 단가와 텍스트 크기·최대 출력 토큰으로 먼저 예약한다. SDK 재시도도 각각 예약한다.
- 확인된 응답 usage만 정산하고 차액을 돌려놓는다. 타임아웃·오류·불명확한 사용량은 예약액을 유지한다. 결과가 불분명한 유료 요청을 무료였다고 가정하지 않는다.
- 모델 미등록, 비텍스트 요청, 예산 RPC 장애, 한도 초과는 공급자 호출 전에 차단한다.
- 프로필 생성 한도 도달 시 직접 작성으로 이어진다. 기능 플래그 OFF 자체가 모든 AI 비용을 0으로 만들지는 않는다.
- 내부 환산은 1 USD = 1,800원에 10% 여유를 적용한다. 캐시 입력도 보수적으로 계산한다. **공급자 카드 청구액 보장은 아니며**, 공급자 가격 변경 시 단가표를 함께 검토해야 한다. 공급자 콘솔의 별도 지출 한도도 병행할 수 있다.
- 예산 장부에는 요청 ID·모델·시간·금액만 기록한다. 회원 식별자·대화·프로필·비밀 키는 넣지 않는다.

구현: `supabase/functions/_shared/ai-budget.ts`, `20261101170000_beta_readiness.sql`.
모델 단가 출처: [Anthropic Sonnet 5.5](https://www.anthropic.com/claude-sonnet-5-5).

## 운영자가 매일 할 일

1. 운영 홈의 기한 초과 사진 검토와 약속 확인 연락을 먼저 처리한다. 24시간 검토 목표를 지키기 어려우면 고객 문의로 진행 상황을 안내한다.
2. 큐레이션에서 실제 호감·프로필·가능 시간에 맞게 소개를 배정한다. 심사 승인만으로 소개 풀이 자동 확보되지는 않는다.
3. 외부 알림 개통 전에는 **별도 연락에 동의한 회원만** 수기로 연락하고 작업함에 결과/다음 확인 시각을 기록한다. 앱 알림 생성·읽음과 실제 외부 전달은 구분한다.
4. 약속 후 후기·신고를 확인한다. 후기는 상대에게 공개되지 않으며 쓰지 않았다는 이유만으로 다음 소개를 영구 차단하지 않는다.
5. AI 예약액 포함 사용량과 실패를 확인한다. 응답이 불명확한 예약액을 임의로 삭제해 추가 호출을 허용하지 않는다.

기존 안전 정책 정정: D-2h 양측 미응답 취소·경고는 양측이 확인 알림을 읽었을 때만 진행한다. 알림 미열람·한쪽만 응답한 경우 운영 확인으로 넘긴다. 만남 요청 자체의 24시간 만료는 티켓을 복구하되 미응답 경고를 부과하지 않는다.

## 오픈 판단과 남은 게이트

**수기 운영 가능한 소수 초대 베타**와 **무인 공개 상용 오픈**을 구분한다. 코드 통과만으로 아래 항목이 완료되지는 않는다.

- 외부 약속/취소/후기 알림 실제 수신·딥링크 복귀·실패 재처리: 미개통. 개통 전 소수 초대와 동의된 수기 연락이 필요하다.
- LIVE KCP 성인 본인인증, 실결제/취소: 외부 계약·키·실시나리오 검증 후 별도 활성화. 테스트 인증을 LIVE 인증으로 승격하지 않는다.
- 운영 관리자 MFA 재로그인·복구수단 확인: 사용자 확인 필요. 이번 변경은 강제를 켜서 운영자를 잠그지 않는다.
- 운영 카카오 로그인 전체 왕복, 실제 LLM 품질/p95, 저사양 실기기·48시간 운영 관찰: 이번 합성 QA의 통과 범위가 아니다.
- 선택형 회사 인증 배지, 후기 기반 동의된 선호 개인화, 카카오 신규 가입 단축은 후속 개선이다. 현재 기능인 것처럼 표시하지 않는다.
