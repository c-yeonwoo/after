# 홈·소개·프로필 동선 정리 검증

2026-10-29. 로컬 UI·서버 동의 계약 검증을 완료했다. 운영 비서 플래그를 변경하지 않았으며 실제 LLM 품질 승인이나 전체 만남 사이클 재검증을 뜻하지 않는다.

## 반영

- 홈은 현재 상태와 필요한 다음 행동, 마지막 상담 질문·답변 한 쌍, 입력창에 집중한다. 전체 대화는 같은 저장소의 과거 상담·작업 기록을 보여준다.
- AI 맞춤 상담 선택 동의는 가입 첫 단계에서 기록하고 검증된 가입 세션의 실제 소유자에게 원자적으로 귀속한다. 기존 회원은 별도 첫 상담 동의 화면을 이용한다. 홈의 긴 동의문은 제거했다.
- 소개 탭에 새 소개·만남 전환을 두었다. 만남 요청부터 날짜 조율·확정 약속·상대 채팅까지 같은 허브에서 찾는다.
- 내 프로필을 공통 진입점으로 두고 사진·기본정보 직접 수정과 소개글 AI 다듬기를 구별했다.
- 초기화 확인 버튼을 공통 파괴적 행동 스타일로 정리했다. 남성 상점은 무료 베타 마이페이지에서도 접근 가능하며 여성 구매 제한은 그대로다.

## 검증

| 검사 | 결과와 범위 |
| --- | --- |
| npm run check | 타입·lint·순수 회귀·색 대비·프로덕션 빌드 PASS |
| SQL | s116 신규 동의 19 + s115 보관 16 + s73 가입 28 = 63 assertions PASS. BEGIN/ROLLBACK, 기존 회원·진행·설정 보존 |
| 화면 | 14 화면 × 320/390/1440px × light/dark = 84 PASS |
| 마지막 변경 재검증 | 가입 동의·홈 도착·홈 최근 대화·기존 회원 동의·기능 OFF 홈, 30 PASS. 앞선 화면과 중복이 있어 단순 합산하지 않음 |
| 계정 전환 | A의 동의 응답이 늦게 와도 B의 체크 상태·화면 이동에 적용되지 않음. 제한 시간 있는 회귀 테스트 통과 |
| 독립 리뷰 | 동의 화면 계정 전환 P2 수정, 회귀 테스트 무제한 대기 제거. 앱 신규 P1/P2 없음 |

화면 검사는 모든 backend 응답을 합성 fixture로 격리했다. 외부 API·유료 모델 호출, 실제 회원 연락 없이 접근성·오버플로·핵심 동선을 검사했다. 근거는 `/tmp/after-home-focus-final/summary.json`, `/tmp/after-home-focus-release/summary.json`이다.

공유 로컬 DB의 전역 설정을 변경하는 전체 브라우저 suite는 실행하지 않았다. 기존 manual/tour 계정과 5191/5192 서버를 유지했다. CI에서는 격리 DB로 전체 suite를 실행한다. 이전 main CI의 낡은 가입 완료 문구 선택자 2곳도 현재 ‘내 매니저가 생겼어요.’로 갱신했다.

## 남은 경계

운영 상담·기억·일정·프로필 AI 수정·상대 소개 AI는 계속 OFF다. 실제 상대 소개 LLM의 사실성 검증 실패와 실기기·외부 인증·실결제 항목은 이 UI 작업으로 완료 처리하지 않는다. 이전 상세 근거는 [매니저 검증 기록](personal-manager-reading-2026-10-28.md)에 있다. 배포 완료는 PR 머지 여부만으로 판단하지 않고 main 배포와 운영 app-version으로 별도 확인한다.
