# 프로필 문장 생성

가입 마지막 화면에서 모델이 한 줄 소개 후보 3개와 소개글 1편을 씁니다.
켜려면 **API 키를 넣어야 합니다.** 키가 없으면 화면은 예전처럼 규칙 기반
초안을 그대로 보여 주고, 오류도 나지 않습니다.

---

## 켜는 법

### 운영

```bash
npx supabase secrets set ANTHROPIC_API_KEY=sk-ant-...
npx supabase functions deploy compose-profile
```

### 로컬

`supabase/functions/.env` 에 한 줄을 넣습니다. 이 파일은 `.gitignore` 에
들어 있어 커밋되지 않습니다.

```
ANTHROPIC_API_KEY=sk-ant-...
```

그다음 `npx supabase functions serve` 로 띄웁니다.

---

## 설계 메모

### 왜 Edge Function 인가

이 프로젝트는 `VITE_*` 값을 **빌드 시점에 정적으로 치환합니다**
(`vite.config.ts` 의 `envDefine`). 클라이언트에 키를 두면 번들에 문자열로
박히고, 번들은 공개됩니다. 그래서 모델 호출은 반드시 서버를 거칩니다.

### 실패하면 조용히 지나갑니다

키가 없든, 모델이 거절하든, 시간이 초과되든 `composeProfile()` 은 예외를
던지지 않고 `null` 을 돌려줍니다. 화면에는 규칙 기반 초안이 이미 떠 있고,
문장이 더 좋아지지 않았다고 가입을 막을 이유가 없습니다.

### 보내지 않는 값

회사 이메일, 이름, 생년월일은 이 함수에 보내지 않습니다. 문장을 쓰는 데
필요 없는 값이고, 필요 없는 값을 외부로 내보내면 그 자체가 노출면입니다.

### 같은 답변으로 두 번 부르지 않습니다

호출마다 돈이 나갑니다. 이전 단계로 갔다가 돌아오는 일이 잦은 화면이라,
답변이 그대로면 이미 받은 결과를 다시 씁니다. 답변을 고치면 키가 달라져
자연스럽게 다시 부릅니다.

### 모델과 비용

| 항목 | 값 |
|---|---|
| 모델 | `claude-opus-5` |
| effort | `low` (짧은 카피 작업이라 깊게 생각할 이유가 없습니다) |
| max_tokens | 2000 |
| 1회 비용 | 15원에서 20원 사이로 **추정**합니다. 실제 값은 켠 뒤에 측정해야 합니다 |

### 왜 서버 사이드 fallbacks 를 쓰지 않는가

Claude Opus 5 에는 안전 분류기가 거절했을 때 다른 모델로 넘기는 `fallbacks`
파라미터가 있습니다. 다만 그건 beta 네임스페이스를 거쳐야 하고, 구조화 출력
헬퍼(`messages.parse`)와 함께 쓰는 형태를 확인하지 못했습니다. 확인하지 못한
API 를 추측해서 쓰지 않습니다. 대신 거절이면 422 를 돌려주고 화면이 규칙 기반
초안으로 되돌아갑니다. 소개글 쓰기라 거절이 날 이유가 거의 없습니다.

### 의존성 함정

`zodOutputFormat` 은 **zod 4** 의 `toJSONSchema` 를 씁니다. v3 스키마를 넘기면
`Cannot read properties of undefined (reading 'def')` 로 죽습니다. 함수는
`npm:zod@4.5.4` 로 고정했습니다. 앱의 `package.json` 은 zod 3 그대로이고,
Deno 함수와 브라우저 번들은 모듈 그래프가 달라 서로 간섭하지 않습니다.

`.length(3)` 은 JSON Schema 로 나갈 때 설명 문자열이 될 뿐 강제되지 않습니다.
개수는 프롬프트로 한 번, 응답을 자르는 코드로 한 번 더 잡습니다.

## 문체 지침을 프롬프트에 적는 이유

기본값으로 두면 모델은 자기 문체로 씁니다. 병렬 구조로 나열하고, 형용사를
겹쳐 쓰고, 문장을 대구로 맞춥니다. 그 글은 **누가 썼는지 알아볼 수 있습니다.**

소개팅 프로필에서 그것은 치명적입니다. 열 명의 프로필이 서로 닮으면 읽는
사람이 구분하지 못하고, 구분되지 않으면 고를 이유도 없습니다.

그래서 `SYSTEM` 에 금지 항목을 구체적으로 적었습니다. "자연스럽게 써라" 같은
지시는 모델이 이미 자연스럽다고 여기는 문체를 강화할 뿐입니다.

문장이 여전히 비슷해 보이면 그 목록부터 손보면 됩니다.
